# Nikolaj Kevlich Portfolio

Personal portfolio built with React, TypeScript, Vite and SCSS modules.

## Scripts

### `yarn start`

Runs the Vite dev server.

### `yarn build`

Runs TypeScript checks and builds production assets into `dist/`.

### `yarn preview`

Serves the production build locally.

### `yarn deploy`

Builds the app and publishes `dist/` to GitHub Pages.

## Environment

Use `VITE_BASE_URL` for the contacts API base URL.
